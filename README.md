# 🏛️ AURA - Automate University Record & Attendance Platform

AURA is a comprehensive university management web application that automates student directory tracking, daily attendance logging, academic marks rosters, executive analytics dashboards, and automated low-attendance email warning notifications (< 75% threshold).

---

## 🚀 Key Features
* 📊 **Executive Dashboard**: Real-time KPI metrics, attendance percentage ratios, and interactive Chart.js visualizations.
* 👨‍🎓 **Student Directory**: Multi-criteria search and department filters for enrolled students.
* 📅 **Daily Attendance Board**: One-click attendance marking with historical log tables and CSV exports.
* 📚 **Academic Marks Roster**: Internal (30) and external (70) exam score entries with automated letter grade evaluation.
* 🔔 **Low Attendance Alert System**: Automatic detection of students below 75% attendance with required recovery class calculations.
* 📧 **Live SMTP Email Broadcasting**: Secure TLS-encrypted dispatch of attendance warning notices directly to student inboxes.
